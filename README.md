# 다다의 복권방

로또 6/45 번호 생성과 내 복권 당첨 확인을 위한 개인용 아이폰 웹앱(PWA)입니다.

- 당첨 확률을 높여 주지 않습니다. 어떤 번호든 1등 확률은 같습니다.
- 구매 기록은 휴대폰 안(IndexedDB)에만 저장되며 이 저장소나 외부로 보내지 않습니다.
- 판정 결과는 참고용이며, 최종 당첨 여부는 동행복권 공식 조회와 실물 복권으로 확인하세요.

## 개발

- 원본: `app.html`, `lib/`, `sw.template.js`
- 배포 파일 생성: `node build.mjs` → `index.html`, `sw.js`
- 테스트: `node --test`

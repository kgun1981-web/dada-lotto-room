# 다다의 복권방

로또 6/45 번호 추천과 내 복권 당첨 확인을 위한 개인용 아이폰 웹앱(PWA)입니다.
배포 주소: https://kgun1981-web.github.io/dada-lotto-room/

- 어떤 번호든 1등 확률은 같습니다. 통계 추천은 당첨 가능성을 높인다는 근거가 없으며, 과거 검증 결과를 함께 보여 줍니다.
- 구매 기록과 직접 입력한 당첨번호는 휴대폰 안(IndexedDB)에만 저장되며 이 저장소나 외부로 보내지 않습니다.
- 판정 결과는 참고용입니다. 최종 당첨 여부는 동행복권 공식 조회와 실물 복권으로 확인하세요.

## 당첨번호 (자동 수집 중지)

- 1~1248회: 2026-11-03 동행복권 결과 화면에서 받은 자료. **공개 저장소에는 올리지 않고 휴대폰 안(IndexedDB)에만 보관** (DESIGN.md 19절). 처음 한 번 앱의 백업 탭에서 당첨번호 파일을 불러옴
- **2026-11-04 자동 수집 중지**: 동행복권 사이트 이용약관(2025.07.29 시행) 제12조 ①항
  - 1호 "회사가 제공하는 서비스 이용방법에 의하지 아니하고 비정상적인 방법으로 서비스를 이용하거나 시스템에 접근하는 행위"
  - 9호 "특정 기능을 반복적 또는 규칙적으로 호출하는 행위"
  - 매주 정해진 시간에 조회 기능을 직접 부르는 방식이 이에 해당할 수 있어 예약·자동 실행을 모두 끔. 수집기는 `ALLOW_DHLOTTERY_FETCH=yes` 없이는 바로 종료
  - 동행복권의 명시적 허락(공식 API 또는 제공 동의)을 받기 전까지 다시 켜지 않음
- 1249회부터: 앱의 "당첨번호" 탭에서 직접 입력 (상태 `user_entered`, 판정에 "공식 결과와 대조 필요" 표시)
- 수집기 코드·실패 주입 테스트는 기록과 재사용 대비로 남겨 둠

## 문제가 생겼을 때

### 앱에 "○회 당첨번호를 직접 입력해 주세요"가 보일 때
토요일 추첨 결과를 동행복권 앱·홈페이지에서 보고 "당첨번호" 탭에 입력

### 휴대폰 당첨번호 자료가 지워졌을 때
1. 앱 상단에 "당첨번호 자료가 없어요"가 보이면 백업 탭 → 파일 선택에서 보관해 둔 `다다의복권방_당첨번호_1-1248회.json` 또는 최근 백업 파일을 불러오기
2. 1249회 이후 직접 입력한 당첨번호는 백업 파일에 들어 있음

## 통계 추천

- 규칙과 평가 구간은 `DESIGN.md` 16절에 과거 검증 실행 전에 등록(커밋 c5deff0)
- `lib/stats.js`: 추천·번호 통계·과거 검증. t회 추천은 t-1회까지 자료만 사용(테스트로 확인)
- `tools/backtest.mjs` → `draws/backtest.json`: 601~1248회 사전 등록 구간 결과. 1249회~(등록 후)는 앱 안에서 직접 입력한 당첨번호로 바로 계산
